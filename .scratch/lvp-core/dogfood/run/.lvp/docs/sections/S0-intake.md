# S0 — Intake

## Idea (verbatim, id)

Aplikasi booking lapangan futsal dengan DP online dan jadwal real-time. Pemilik lapangan kelolanya masih pakai buku tulis, sering bentrok jadwal. Pemain booking dari HP, admin kelola dari laptop. Pengen ada DP 30% biar nggak jadi-no-show.

> Summary (EN): A booking app for small futsal venues with an online 30% down payment (DP) and real-time schedules. The owner still manages bookings in a paper notebook and WhatsApp chats, which causes double-booked slots. Players book from their phones; the admin manages from a laptop. The 30% DP is meant to cut no-shows.
